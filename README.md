# CXI-AI-Group-4
Our solution to the CPfizer CXI-AI challenge at the University of Liverpool

## Component Selector
We will make a component selector that assumes a design system is given. It will then select react components for you, justify it's decision and render a mock up that you can look at.

The selector allows users to drag and drop a brief and elements of their design system into the browser. It then formats these into a prompt and queries an cloud AI. The response is parsed into an output and displayed on the page, including justification for all the decisions.
